# 创新大赛评分系统 (Innovation Contest Scoring System)

## 项目简介
基于纯 C 语言 (`.c`/`.h`) 开发的命令行创新大赛评分系统。采用 VS2026 开发，纯手写单链表数据结构，无 C++ 特性，采用 9 文件分离式编译架构。

## 文件架构设计

*   **`main.c`**
    *   程序的唯一入口。
    *   负责系统启动、角色选择菜单、以及退出系统的控制循环。
*   **`common.c` / `common.h`**
    *   提供四个安全输入函数：`safechar`（字符）、`safestr`（字符串）、`safenumber`（数字，底层调用 `safestr` 保证安全）、`safelogin`（登录专用）。
    *   提供通用 UI 逻辑：`chooserole`（身份选择）、`is_again`（询问是否再次进入系统）。
*   **`list.c` / `list.h`**
    *   定义底层数据结构：`work` 结构体和 `Node` 单链表节点。
    *   定义核心数据操作：增加节点、删除节点、按 ID 查找并返回前驱指针、打印单条 `work` 信息。
    *   定义 5 种底层查找算法：按 ID 查、按作品名查、按作者名查、按学号查、按关键词模糊查（`strstr`）。
*   **`admin.c` / `admin.h`**
    *   包含管理员 (`admin`) 的登录验证、主界面菜单控制。
    *   核心 9 大功能模块：创建、删除、查找、修改、发布、保存、计算平均分、作品排序、退出系统。
    *   *(当前进度：已完成 2/9，即创建作品、删除作品)*
*   **`judge.c` / `judge.h`**
    *   包含评委 (`judge`) 的登录验证、主界面菜单控制。
    *   核心 4 大功能模块：从文件导入作品、查询作品、给作品评分、保存评分。
    *   *(当前进度：已完成基础框架与菜单 UI，具体业务逻辑待实现)*

## 开发规范
1. **工程化思维**：`list.c` 仅负责纯数据处理和链表遍历，绝不包含 `printf` 的 UI 提示和 `getchar` 阻塞；所有 UI 交互统一交由 `admin.c` / `judge.c` 业务层处理。
