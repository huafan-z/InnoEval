# 创新大赛评分系统 (Innovation Contest Scoring System)

## 项目简介
基于纯 C 语言 (`.c`/`.h`) 开发的命令行创新大赛评分系统。采用 VS2026 开发，纯手写单链表数据结构，无 C++ 特性，采用 9 文件分离式编译架构。

## 文件架构设计

*   **`main.c`**
    *   程序的唯一入口。
    *   负责系统启动、数据文件加载校验、管理员/评委身份选择菜单、以及退出系统的控制循环。
*   **`common.c` / `common.h`**
    *   提供安全输入函数：`safechar`、`safestr`、`safenumber`、`safelogin`。
    *   提供通用 UI 逻辑：`chooserole`（身份选择）、`is_again`（再次进入询问）。
    *   提供分页查询引擎 `queryOut` 及分页展示逻辑（`printOnePAGE`、`printPAGE`）。
    *   提供修改与发布的具体业务辅助函数：`MoTitle`、`MoAuthor`、`MoAu`、`PubOne`、`PubAll`、`UnpubOne`。
*   **`list.c` / `list.h`**
    *   定义底层数据结构：`work` 结构体和 `Node` 单链表节点，维护全局变量 `WORK_SUM`、`UNPUBLISH` 等。
    *   **文件读写**：
        *   `loadWorkFromFile`：使用 `|` 作为分隔符，通过 `sscanf` 格式化字符串读取数据，并进行错误校验。
        *   `WorkToFile`：将链表数据写入临时文件，校验后重命名替换原文件，保护数据安全。
    *   **数据操作**：增加节点、删除节点、按 ID 查找、批量发布 (`Publish_All`)。
    *   **查找算法**：按标题、作者、学号、关键词（`strstr`）进行底层遍历查找。
*   **`admin.c` / `admin.h`**
    *   包含管理员 (`admin`) 的登录验证、主界面菜单控制。
    *   核心 8 大业务功能模块：创建、删除、查询、修改、发布/撤回、保存、计算平均分、作品排序。
    *   *(当前进度：已完成 6/8，即创建作品、删除作品、查询作品、修改作品、发布与撤回作品、保存作品)*
*   **`judge.c` / `judge.h`**
    *   包含评委 (`judge`) 的登录验证、主界面菜单控制。
    *   核心 3 大功能模块：查询作品、给作品评分、保存评分。
    *   *(当前进度：已完成 0/3，仅搭建了 `jud_run` 的主菜单框架与输入接收)*

## 开发规范
1. **工程化思维**：`list.c` 仅负责纯数据处理和链表遍历，绝不包含 `printf` 的 UI 提示和 `getchar` 阻塞；所有 UI 交互统一交由 `admin.c` / `judge.c` / `common.c` 业务层处理。
2. **输入安全**：所有用户输入均经过安全封装，杜绝缓冲区溢出、空输入和非法字符导致的崩溃。
3. **数据安全**：读写文件时严格校验返回值，写入时采用 `tmp` 临时文件替换法，保护数据不被意外清空。
